# 卡 B · 麻醉访视医生　⭐⭐

> 时机：国内麻醉访视常在**术前一晚或术日晨**——不要写死"周日"（附录 1 第 4 条）。
> 递交版：[卡B-麻醉访视-用药与镇痛确认单](../递交版/卡B-麻醉访视-用药与镇痛确认单.md)——**先把药名 / 剂量 / 其他用药 / 过敏史四个空填好再递**。

---

## ① 降压药 ⭐⭐

v3 原句：「她每天吃氨氯地平，手术当天早上还吃吗？」

⚠️ **待核实（附录 1 第 3 条）**：仓库病历只写"高血压"，**没有药名 / 剂量**。请先核实：是不是氨氯地平、每天几点吃、多少 mg。麻醉医生反问时，你能报出药名和剂量，可信度完全不同。递交版已改成空格。

➕ **①b**「术前**禁食禁饮到几点**？她早上吃降压药，用多少水送服？」

【注】氨氯地平≠抗凝药　【因】通常照吃（清晨一小口水），但须麻醉医生亲口定　【源】术前药物管理常规

## ② 停药确认 ⭐

「还有要提前停的药吗？她没在用抗凝药吧？」

➕ **②b ⭐** 家属先核实：有没有同时吃**活血中药 / 阿司匹林 / 氯吡格雷 / 鱼油 / 维生素 E**（这些才真正影响手术）。有就写在递交版第 3 条里。

## ③ 镇痛 ⭐⭐

「术后镇痛什么方案？有镇痛泵（PCA）吗？她对痛敏感。」

➕ **③b ⭐⭐**「镇痛泵里是什么药？**会不会加重便秘 / 腹胀？**」
　【因】她有肠梗阻风险，术后要尽早排气；阿片类抑制肠蠕动，便秘 / 腹胀反而会掩盖肠梗阻信号。

➕ **③c ⭐**「能不能加做**腹横肌平面阻滞（TAP）或切口局麻**，少用一点阿片？」

【注】PCA＝自控泵，有锁定间隔不会过量　【因】镇痛好＝敢咳敢动＝肺炎血栓都少　【源】ERAS 常规

## ④ 止吐 ⭐

「她容易恶心，术后止吐怎么安排？」

➕ **④b ⭐**「恶心呕吐风险算高危（女性、不吸烟、术后用阿片）。**会做三联预防吗**（如昂丹司琼＋地塞米松＋NK1）？」

【因】吐＝吃不下＝46kg 掉不起

## ⑤ 过敏 ⭐

「过敏史对一遍——她有没有药物过敏？」（家属先知道答案，写进递交版第 4 条）

## ⑥ 复苏室

「术后待多久？家属什么时候能见？」

➕ **⑥b**「她右下肺叶已切除。术后要不要**雾化 / 呼吸训练**？第一晚需要人陪吗？」

## ⑦ 抗凝（**本卡最大缺口**）⭐⭐

➕「她 D-二聚体 2.22、FDP 6.9、纤维蛋白原 4.9，属高凝状态。**术后抗凝（低分子肝素＋间歇充气加压）什么时候开始、什么时候停？**」
　【注】低分子肝素与硬膜外 / 腰麻有配合要求，由麻醉和外科共同定。
　【因】妇科肿瘤大手术＋高凝＝血栓高危；术后血栓比出血更容易被漏掉。【源】ERAS ／ VTE 预防常规。
