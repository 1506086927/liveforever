**出现下列任一条，立刻行动——不要等查房。**

## A. 立刻打 120 ／ 马上叫护士

- 喘不上气、胸痛、嘴唇发紫、说话不成句
- 血压很低 / 头晕要倒、意识改变、叫不醒、抽搐
- 阴道大出血（1 小时湿透一条大垫）、面色苍白、心率很快
- 无尿超过 6–8 小时，或腰痛剧烈＋尿少

## B. 当天就叫医生处理

- 体温 **≥38.5℃** 或寒战发抖
- 腹痛突然加重、肚子硬、按不得
- **引流液突然增多 / 变红 / 变浑浊 / 有粪样物或气泡**（肠瘘信号，本患者要特别盯——骶前病灶与直肠 / 乙状结肠分界不清）
- 切口红肿、渗液、裂开
- 一条腿肿、痛、发热（深静脉血栓——她本就高凝）
- 术后超过 3 天**没排气**、腹胀、呕吐（肠梗阻）
- 心慌、出冷汗、饿得慌（低血糖 / 低钾——她 K 历史 3.36↓）
